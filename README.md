# 東京偶像公主・偶像學園（偶活）尋店

Static Tokyo shop finder. 169 アイプリ shops and 118 アイカツ！アンコール shops retained separately. 229 station choices across 14 routes. Independently drawn two-dimensional SVG with Yamanote loop, route highlighting, zoom and pan.

Distances are straight-line estimates, not walking distances. Address/block/town precision is shown; official installation lists do not confirm stock.

Serve this folder over HTTP, e.g. `python3 -m http.server 8080`. No API key, account, build dependency, ads or paid service required.

See `shop-sources.txt`, `station-sources.txt`, and `schematic-sources.txt` for data provenance and applicable third-party terms. Original Tokyo Metro artwork is not included. Third-party data retain their respective terms; no blanket license is claimed for shop lists.
